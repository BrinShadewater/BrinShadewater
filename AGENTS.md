# AGENTS.md — 👋 this repo is a shop window

`README.md` here is the **GitHub profile README**. It renders at
[github.com/BrinShadewater](https://github.com/BrinShadewater) and is the first
thing anyone sees — recruiters, collaborators, people arriving from a project.

There is no app, no build, no tests. The whole repo is one file, and the stakes of
editing it are presentational rather than technical.

## 🔒 Two things that would break it silently

1. **The repo name must stay exactly `BrinShadewater`.** GitHub renders a profile
   README only from a repo whose name matches the username. Rename it and the
   profile page goes blank with no error anywhere.
2. **Links must be absolute.** Relative markdown links resolve *inside this repo*,
   not against the profile page, so a relative link renders as a dead link on the
   profile even though it looks fine in the repo's own file view.

## ✅ Editing rules

- **Every claim here is factual and about a real person.** Film credits, a
  theatrical release, streaming availability, live site URLs. Do not embellish,
  do not round numbers up, and do not add a credit or a claim that has not been
  confirmed. If a fact needs updating, update it — but invent nothing.
- **Check the links still resolve** when you touch them. A profile full of 404s is
  worse than a shorter profile.
- **Keep the voice.** Dry, specific, a little self-aware, emoji used as punctuation
  rather than decoration. It reads like a person, not a résumé. Do not make it
  corporate, and do not turn the prose into bullet-point keyword soup.
- **Tables and emoji must render on github.com.** Preview the markdown as GitHub
  renders it rather than trusting a local viewer.

## 🗺️ What it points at

The README is a hub for the public work — Data Goblin, Strange Harvest, Ink Master
Studio, Lost Hills Online, Shadewater Labs. When a project's positioning changes,
this file is the last place to notice, so it is worth a look whenever a public repo
description or site copy changes. Keeping it consistent with those descriptions is
the point of it existing.
